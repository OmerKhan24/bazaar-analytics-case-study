# 📊 Bazaar Analytics Case Study – Internship Challenge 2025

Welcome! This repository contains the complete solution to the **Bazaar Technologies Analytics Internship Case Study – Round 2**. The analysis was done using Python (Pandas, Matplotlib), and SQL queries were crafted to extract business insights from real-world datasets.

---

## 🚀 Objective

The goal of this case study was to analyze **user signups and order data** from Bazaar's online grocery platform to:
- Understand customer behavior
- Improve first-order conversion rates
- Increase repeat purchases
- Optimize order fulfillment
- Provide data-backed growth recommendations

---

## 📁 Files Included

- `bazaar_analysis.ipynb`: Jupyter Notebook with complete Python analysis and visualizations.
- `SQL_queries.sql`: SQL queries for key data extraction tasks.
- `charts/`: Folder containing key visualizations (PNG format).
- `slides/`: Final PowerPoint presentation submitted.

---

## 🧠 Key Insights

- Calculated conversion rates from sign-up to first order
- Identified most effective acquisition platforms
- Measured total sales, AOV, and cancellation rates
- Recommended strategies for growth and retention

---

## 🛠️ Technologies Used

- **Python** (Pandas, Matplotlib)
- **SQL**
- **Jupyter Notebook**
- **Excel (openpyxl)**

## ▶️ How to Run

1. Clone the repository:
```bash
git clone https://github.com/yourusername/bazaar-analytics-case-study.git
```
2. Open bazaar_analysis.py in VS Code.
3. Ensure you have the required Python packages installed:

```
pip install pandas matplotlib openpyxl
```

4. Run the .py file to explore the visualizations and printed insights.

All SQL queries are included in the SQL_queries.sql file and are also referenced within the final presentation slides.
